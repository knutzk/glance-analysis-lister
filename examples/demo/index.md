# Interactive demo

Explore the four generated pages using the navigation. All records, people,
identifiers and dates are invented. External record links are examples and do
not identify real analyses or publications. Search and filtering run locally
in your browser.

| Page | What to try | Expected result |
| --- | --- | --- |
| Ongoing analyses | Click the analysis title, then search for `Invented keyword`. | The card expands; its details match the search. |
| Papers | Select only **Under review**. | The paper disappears because it has an invented DOI. **Reset** restores it. |
| Conference notes | Select only **Superseded**. | The note disappears because it has no superseding record. **Reset** restores it. |
| Public notes | Set **Released before** to January 2099. | The note disappears because its release date is 1 March 2099. **Reset** restores it. |

Each page starts with one record. Titles expand the details; **Expand all** opens
all visible records. You can also focus a title and press **Enter** or **Space**.
Search and filter choices are stored in the page URL, so reloading preserves
them. The light/dark switch changes the site's colour scheme.
