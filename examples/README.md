# Synthetic example

This snapshot was constructed from empty model fields and invented values,
without reading any GLANCE snapshot. It contains an ongoing analysis, a published
paper, a CONF note and a PUB note, shared across the three supported subgroups.

All `DEMO-2099-*` references, people, titles, dates and note numbers are fictional.
The `example.test` URLs are placeholders. The renderer also constructs GLANCE
links from the fictional references; those links do not identify real records.

The matching lookup dictionaries contain only synthetic titles. They demonstrate
the same `--lookup-dir` option used for private lookups, and avoid notices about
production lookup entries that do not belong to this example.

Run the commands in the main README from the repository root. Generated `pages/`
and `obsidian_output/` directories are ignored by Git. Only this specifically
named synthetic JSON file is exempted from the general JSON ignore rule.
